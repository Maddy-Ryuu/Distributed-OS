Six major design goals

DISTRIBUTED OS The design of a distributed operating system focuses on these six goals, which together decide how effective it will be.
01 DESIGN GOAL

Transparency

Hide the complexity of distributed resources from users and programs.

Local File Path on Workstation 1: C:\Users\Student\Documents\Exam_Grades.csv
How Distributed OS Achieves This: The Virtual File System (VFS) intercepts local system calls and maps them to remote addresses (`192.168.1.50:/var/db/`) without the user needing to know physical network locations.
02 DESIGN GOAL

Openness

Support standard interfaces and protocols so different systems interoperate.

🐧 Node 1: Linux POSIX 🪟 Node 2: Windows NT 🍎 Node 3: macOS Darwin
How Distributed OS Achieves This: Conforms to open RFC standards and standard IDL (Interface Definition Language), preventing vendor lock-in and allowing Linux, Windows, and macOS to communicate seamlessly.
03 DESIGN GOAL

Scalability

Handle increasing numbers of users, resources and locations.

5 Connected Workstations
75.0 Cluster Capacity (GFLOPS)
How Distributed OS Achieves This: Modular decentralized algorithms and peer-to-peer discovery avoid central bottlenecks, enabling smooth horizontal expansion as demand grows.
04 DESIGN GOAL

Reliability

Continue functioning despite component failures.

PRIMARY
Server DB-01
ONLINE (100% HEALTH)
STANDBY REPLICA
Server DB-02
SYNCED & READY
How Distributed OS Achieves This: Data replication and consensus protocols (Raft/Paxos) detect heartbeat timeouts and promote standby nodes with zero user downtime.
05 DESIGN GOAL

Performance

Use distributed resources efficiently and keep communication overhead low.

Distributed Workload: 600 Records / 3 Parallel Threads
How Distributed OS Achieves This: Intelligent load balancing, caching, and thread partitioning maximize CPU parallelism while minimizing inter-node network round-trips.
06 DESIGN GOAL

Flexibility

Support different hardware and software environments.

⚡ Node 1 x86_64 Multi-Core CPU (Compilation Task)
🔋 Node 2 ARM64 Low-Power SoC (Edge Sensor I/O)
🚀 Node 3 NVIDIA Tensor GPU (Deep Neural Inference)
How Distributed OS Achieves This: Microkernel architectures separate policy from mechanism, abstracting varied CPU instruction sets (x86, ARM) and accelerators into a single unified API.
